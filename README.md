\# World Bank Sanitation Data Engineering \& Analytics Pipeline



An end to end data engineering and analytics project that uses World Bank data to explore access to basic sanitation services across countries and over time.



\## Project Overview



Access to basic sanitation is an important measure of public health, living conditions, and sustainable development.



In this project, I built a data pipeline that collects sanitation data from the World Bank API, cleans and prepares it for analysis, stores it in PostgreSQL, and generates insights through exploratory analysis, machine learning, AI assisted analysis, and data visualization.



The project focuses on the following World Bank indicator:



\*\*People using at least basic sanitation services (% of population)\*\*



\*\*Indicator Code:\*\* `SH.STA.BASS.ZS`



\## Project Objectives



The main objectives of this project were to:



\- Collect sanitation data from the World Bank API

\- Prepare and clean the raw dataset for analysis

\- Handle missing values and inconsistent records

\- Store the processed data in a PostgreSQL database

\- Explore sanitation trends across countries and years

\- Identify differences in sanitation coverage

\- Apply analytical and machine learning techniques

\- Use AI to support the interpretation of results

\- Create visualizations to communicate findings clearly

\- Apply testing and logging to improve pipeline reliability
